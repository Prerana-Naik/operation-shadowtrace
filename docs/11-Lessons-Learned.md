# Lessons Learned

## Technical Lessons

Throughout this investigation, I learned how different forensic artifacts provide different pieces of the overall attack.

Rather than relying on a single log file, effective investigations require evidence from multiple independent sources.

I also gained practical experience analysing:

- Authentication logs
- System logs
- Bash history
- User account databases
- Running processes
- Network connections
- Scheduled tasks

---

## Investigation Lessons

This project reinforced several important DFIR principles:

- Always follow the evidence.
- Never assume without verification.
- Correlate multiple evidence sources before reaching conclusions.
- Clearly separate confirmed findings, suspected findings, and unknowns.
- Document every conclusion with supporting evidence.

---

## Professional Growth

Operation ShadowTrace was my first independent Digital Forensics and Incident Response (DFIR) case study.

Rather than completing a guided walkthrough, I approached the investigation by asking questions, analysing evidence, testing hypotheses, and documenting findings as a DFIR analyst would.

This project significantly improved my understanding of incident response methodology and demonstrated the importance of structured documentation throughout an investigation.
